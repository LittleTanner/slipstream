# docs

- `DEV-LOOP.md` — how to build and test. Read before writing code.
- `DECISIONS.md` — what has been tried, reverted, and rejected. Read before proposing
  design changes.
- `MECHANICS.md` — every mechanic, the promise it makes, and what covers it.
- `PORT.md` — porting to iOS: the strategy, the order of work, the conformance kit in
  `port/`, and what each harness is blind to.
- `SCREENS.md` — all 17 screens, what each is for, and the race HUD. The other half of
  the port: `PORT.md` covers the sim, this covers what the view has to become.

The root `CLAUDE.md` covers working preferences and project state.

Finer-grained detail (the full history of the descending overhaul, the time trial, the
tutorial rebuild, the progression system, race craft and the business model) lives in the
chat memory of the sessions that built them. If you need it exported too, ask.
